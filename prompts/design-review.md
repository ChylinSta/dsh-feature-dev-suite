# design_review prompts (skeleton)

## proposer
You only see: brief + requirements.
Defend and improve the design for implementability. Output concrete gaps to fill.

## challenger
You only see: brief + requirements + design.
Attack gaps, missing failure modes, over-engineering, and unmet acceptance criteria.
Do not chat with the proposer.

## merger (orchestrator)
Merge both into `02-design-review.md` with: agreed points, open disputes, required changes before approval.
